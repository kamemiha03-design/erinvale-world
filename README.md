# エリンヴェイル / Erinvale

iPhone Safari を主なプレイ環境として設計する、自由探索型ファンタジー3Dワールド。

## 開発環境

- Babylon.js 8 / WebGL2
- Vite
- GLB / glTF によるアセット読み込み
- iPhone向けタッチ移動・スワイプ視点操作

## 起動

```bash
npm install
npm run dev
```

## ディレクトリ

- `src/main.js` — エンジン起動・ループ
- `src/world/royalCity.js` — 王都のシーン構築
- `src/player/controls.js` — タッチ操作
- `src/style.css` — ローディング画面・HUD・モバイルUI
- `public/assets/` — ライセンス確認済みの3Dモデル・テクスチャ・音源

## アート方針

最終品質は、手作りの箱形ブロックだけで建物を表現するのではなく、細部まで作り込まれた建築GLB、PBRテクスチャ、法線・ラフネスマップ、自然な植生、ベイクドライティング、LODを組み合わせて実現する。無料アセットを導入する場合も、配布元とライセンスを記録する。

## 制作マイルストーン

1. 王都広場の構図・移動・視点操作
2. 酒場・冒険者ギルド・市場・城門の高品質モデルと内装
3. 噴水の水表現、旗・樹木・草の風アニメーション
4. 城・崖上の都市・滝・橋・世界樹
5. 森・湖畔・農村・古代遺跡・雪山をシームレスに拡張
6. 空間音響、昼夜・天候、iPhone向け最適化

## 現在の状態

これは開発の土台となる初期コミット。現時点の王都シーンはレイアウト確認用であり、完成品質のアートではない。高品質アセットとライティングを組み込むアート工程が別途必要。
