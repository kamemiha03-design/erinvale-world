# Assets

Place optimized, license-cleared assets here.

Suggested structure:
- `models/architecture/` — tavern, guild, market, gatehouse, castle pieces (GLB)
- `models/props/` — signs, furniture, barrels, stalls, statues
- `models/nature/` — trees, rocks, plants
- `textures/` — PBR base color, normal, roughness, ambient occlusion
- `audio/ambience/` — licensed environmental recordings

For every imported asset, record its source URL, author, license, and any attribution requirements in `ASSET_CREDITS.md`. Do not copy audio from the YouTube references; use original recordings or assets whose licenses permit redistribution.
